# FerryQR

FerryQR 是一个 Android 扫码应用。把摄像头对准二维码，FerryQR 会用对应的应用打开它。如果没有合适的应用，则直接显示二维码的内容，可以复制、搜索或分享。

[English](README.md)

## 扫码结果

> 存在多个二维码时，可以选择其中一个打开。

**链接：** 如果手机上有应用能打开这个链接，则使用应用打开；否则显示网址，可以用浏览器打开。

**支付宝/微信二维码：** 支付宝二维码会直接在支付宝中打开。由于微信不接受来自外部的扫码结果，FerryQR 检测到微信二维码时只能跳转到微信扫一扫界面，再次扫码即可。

**可选的 LSPosed 助手：** FerryQR 同时是一个 LSPosed 模块。启用模块并勾选微信作为作用域，重启微信后，微信扫一扫会在几秒内看到你刚扫到的二维码，代替摄像头画面，因此能立即识别，无需再次对准，也不必在多个二维码之间选择。启用助手后，结果卡片中的“在微信中再次扫码”会变为“在微信中打开”。助手就绪时，扫码界面会短暂提示。未安装 LSPosed 时，FerryQR 的行为与上文相同。

**微信小程序码：** 带三个定位眼的圆形小程序码没有公开的格式说明，FerryQR 无法识别其内容，但能根据外形认出它。摄像头连续两次看到这种码时，扫码会暂停，并弹出结果卡片，卡片上只有在微信中打开这一个操作；点按之前不会发送任何内容，关闭后同一个码要离开画面才会再次弹出。图片中没有可识别的码、只有这种码时，也会弹出同样的卡片。启用助手时，微信扫一扫会看到图中的这一部分并立即打开；未启用时，会打开微信扫一扫，由你直接扫码，如果是图片，则从扫一扫的相册中选择。

**Wi-Fi：** 显示网络名称和密码，大多数网络可以直接连接。

**联系人和日程：** 可以保存到通讯录或日历。

**通行密钥（Passkey）：** 调用已安装的密码管理器，使用已保存的通行密钥。

**eSIM 激活码：** 跳转到手机的 eSIM 设置。如果手机不接受外部跳转，可以复制激活码，再到 SIM 卡设置里添加 eSIM。

**电话号码、短信、邮箱地址、地图位置和应用链接：** 用相应的应用打开。

**其他内容：** 以文本显示。

## 历史记录

右上角的历史按钮可以查看扫过的码，按日期分组，点开即可再次复制、打开或分享。右上角的清空按钮会删除全部记录。

## 生成二维码

右上角的生成按钮可以把文字转换为二维码。打开时会自动读取剪贴板中的文字并生成；输入框内容改变时，二维码随之刷新。除常规二维码外，还可以选择 Aztec、Data Matrix 和 PDF417。内容超出所选码制的容量时，输入框下方会给出提示。生成的码可以复制到剪贴板，或保存到相册的 Pictures/FerryQR 目录。文字还可以直接在支付宝中打开；启用 LSPosed 助手后，也可以在微信中打开。

## 使用提示

二维码不必对准画面中央，出现在画面中任何位置都能识别。

码很小或距离较远时，FerryQR 会自动放大，也可以双指缩放。

如果一直扫不出来，可以点重置按钮，恢复默认倍数并重新启动相机。

光线较暗时，可使用手电筒按钮照亮。

支持在 FerryQR 中选择相册中的图片扫码，也可在其他应用里把图片分享给 FerryQR，或用 FerryQR 打开图片。分享或打开的图片不会启动相机，结果直接以卡片形式弹出；图片中有多个码时，可以在卡片顶部选择要查看的码。

可将 FerryQR 添加到控制中心的磁贴，快捷打开。

## 隐私

FerryQR 只申请相机权限，无联网能力，不会将二维码内容发送到除目标应用外的第三方。不授予相机权限时，仍然可以识别相册图片中的二维码。

历史记录只保存在本机。生成二维码页面只在打开时读取一次剪贴板。
