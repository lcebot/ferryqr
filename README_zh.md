# FerryQR

注重隐私的 Android 扫码应用，将二维码送到对应的应用中。多数扫码应用扫完只给出文本内容，FerryQR 则将二维码直接交给能处理它的应用或系统功能。

[English](README.md)

## 功能

- **在对应的应用中打开：** 链接交给能处理它的应用；Wi-Fi、联系人、日程、通行密钥、eSIM、电话、短信、邮件和地图位置交给系统中对应的功能。FerryQR 也会解析部分特定二维码并展示内容，目前已支持登机牌二维码中的信息。
- **识别能力更强：** 支付宝、微信的扫一扫中自动放大、从多个二维码中选择等进阶能力，FerryQR 同样具备。本地图片中的二维码也能通过“分享至”或“打开方式”交给 FerryQR 识别，截图后分享给 FerryQR 可快速识别屏幕上的二维码。
- **代替各应用自带的扫一扫：** 各应用的专用二维码，包括微信小程序码，经 FerryQR 扫描后直接在对应的应用中打开，不必再进入各应用自己的扫一扫。部分应用需要启用 [LSPosed 模块](#lsposed-模块)。
- **历史记录与收藏：** 扫描过的二维码保存在本地历史记录中，其中的条目可加入收藏。收藏固定显示在历史记录顶部，支持重命名和排序；可将最多 4 条收藏添加到长按 FerryQR 图标弹出的快捷方式中。
- **展示二维码：** 点击历史记录中的条目可重绘二维码，供他人扫描或保存为图片。可自由切换码制，适配扫码设备；还可放大二维码、调高屏幕亮度，提高扫描成功率。
- **生成二维码和条形码：** FerryQR 支持 ZXing 能生成的全部码制，会根据内容推荐最合适的码制。生成后可分享、复制或保存。
- **快捷设置磁贴：** 添加到控制中心后，下拉即可开始扫码。

## 安装

需要 Android 11 及以上版本和 64 位 ARM 处理器。在 [Releases](../../releases) 页面下载 APK 安装即可。

## LSPosed 模块

部分二维码只有经对应应用的扫一扫识别，才能进入该应用中的特定功能或页面。在 LSPosed 中启用 FerryQR 模块后，FerryQR 会将二维码的内容直接传递给这类应用，在 FerryQR 一处完成原本分散在各应用中的扫码。不启用模块时，FerryQR 最多只能打开这类应用的扫码界面，需要再扫一次；也可尝试先在浏览器中打开，再由浏览器跳转到应用。目前已适配滴滴、美团和微信。米家、小米账号和支付宝提供外部入口，无需模块即可使用。

1. 在 LSPosed 中启用 FerryQR，并在作用域中勾选滴滴、美团和微信。
2. 重启这些应用。
3. 打开 FerryQR，在扫码界面左上角的设置中确认模块已在各个应用中生效。

## 隐私

FerryQR 没有联网能力，扫描、保存和生成的内容始终仅在本地处理和保存，可在设置中拒绝将含敏感信息的二维码保存到历史记录。以下为 FerryQR 为实现应用功能申请的权限。

- **相机：** 用于相机扫码。不授予时，仍可识别图片中的二维码：在 FerryQR 中选择图片，或通过“分享至”“打开方式”交给 FerryQR，均无需任何权限。
- **应用列表：** 用于查询哪些已安装的应用能打开二维码，从而在结果卡片中提供“在某应用中打开”，并在传递页中显示各应用的状态。不授予时，FerryQR 无法判断应用是否已安装，这些打开方式可能不会出现。
- **Wi-Fi 状态：** 用于判断手机是否支持 Wi-Fi Easy Connect。安装时自动授予；在可以关闭此权限的系统上关闭后，无法传递 Wi-Fi Easy Connect 二维码。
- **剪贴板：** 生成二维码页面打开时读取一次剪贴板，将其中的文本自动填入输入框。不授予时，需要手动粘贴。
